# SOC-Portfolio
Welcome to my Security Operations Centre (SOC) Portfolio.

This repository documents my hands-on cybersecurity learning, security investigations, incident response exercises, log analysis, network security investigations and threat detection activities.

The objective of this portfolio is to demonstrate practical SOC analyst skills through realistic security scenarios rather than relying only on theoretical knowledge.

🎯 Objectives:

Investigate security alerts and suspicious activity
Analyse authentication and system logs
Identify Indicators of Compromise (IOCs)
Perform security event triage
Investigate phishing and suspicious emails
Analyse network traffic
Perform vulnerability assessments
Practise incident response procedures
Develop SIEM and log-analysis skills
Map security findings to the MITRE ATT&CK framework
Document investigations using professional incident reports
